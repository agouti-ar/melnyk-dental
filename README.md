# Melnyk Dental | Website prototype

![HTML](https://img.shields.io/badge/HTML-E34F26?logo=html5&logoColor=white) ![Tailwind CSS](https://img.shields.io/badge/Tailwind%20CSS-0891B2?logo=tailwindcss&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

An early Ukrainian-language landing page concept for a dental practice in Dnipro. It includes a rotating set of room photos, treatment summaries and a sample contact form.

To browse the prototype locally, open `index.html`. The page uses plain HTML, JavaScript and Tailwind Play CDN.

The sample form does not deliver appointment requests. For a more recent standalone portfolio case with four languages and a fully labelled booking demo, see [Lumina Dental](https://github.com/agouti-ar/lumina-dental-portfolio).
